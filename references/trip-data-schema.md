# trip-data.json 数据结构

一张行程图的全部内容都在这一个文件里：地图上的点、每天怎么走、右侧卡片的每一行字、左上的标题。
`assets/template.html` 只负责画，不负责内容；改行程只改 JSON，重新 build 即可。

## 顶层

```json
{
  "meta":   { ... 标题 / 副标题 / 浮层 / 脚注 ... },
  "days":   [ ... 每天的时间表与路段 ... ],
  "spots":  [ ... 所有标点 ... ],
  "views":  { "all": {...}, "1": {...}, ... },
  "navData":{ "d1_czn_wd": [[lat,lng], ...] }
}
```

## meta

| 字段 | 说明 |
|---|---|
| `title` | 主标题，例：`广西 崇左—靖西—百色—巴马 7日游 攻略图` |
| `tag` | 右上角的方案后缀，例：`方案D`。不需要就删掉 |
| `tagColor` | 后缀颜色，默认 `#EC4899` |
| `dateRange` | 副标题第一段，例：`2026-09-25 ~ 10-01 · 北京出发` |
| `chips` | 小胶囊 `[{"text":"喀斯特山水","cls":"c1"}]`，`cls` 取 `c1`–`c7` 或 `gray`，建议与当天主色对应 |
| `subNote` | 副标题末尾的灰色小字，例：`建议搭配导航APP实时查看路况` |
| `overviews` | 总览按钮。默认 `[{key:"all",label:"🌏 全部"}]`；跨省长途再加 `{key:"full",label:"🛫 全程总览"}`，并在 `views` 里给 `full` 的视角 |
| `trafficTitle` | 左下浮层标题，例：`🚗 自驾里程 / 耗时参考` |
| `traffic` | 左下浮层条目，字符串数组，或 `{"text":"...","tone":"warn"}` 标红（合计里程用它） |
| `tipTitle` | 右上浮层标题，例：`⚠️ 关键提醒` |
| `tips` | 右上浮层条目（字符串数组）。给空数组会整块隐藏 |
| `footnote` | 右栏最底部说明，**允许 HTML**（`<b>`、`<br>`） |
| `defaultMode` | `"straight"`（默认）或 `"nav"` |
| `minZoom` / `maxZoom` | 默认 4 / 16 |

## days[]

| 字段 | 说明 |
|---|---|
| `n` | 第几天，从 1 起连续。决定颜色、筛选按钮 D{n}、卡片上的 DAY n |
| `color` | 这天的主题色，会同时用在轨迹、标点、卡片头、筛选按钮 |
| `name` | 简短日名，例：`瀑布峡谷`（状态栏用） |
| `date` | 卡片头的日期，例：`09-27 周日` |
| `theme` | 卡片头的主题，比 `name` 长，例：`三叠岭瀑布 + 古龙山大峡谷 → 百色` |
| `rows` | `[[时间, 内容, 图标], ...]`。时间写 `08:00` 或 `上午`；图标是 emoji |
| `foot` | 卡片底部的一行小字。写**当天的坑**，不写景点简介 |
| `pick` | 可选，备选方案的黄色提示框，字符串数组，允许 `<b>` |
| `legs` | 当天所有路段（见下）。空数组 = 这天不画线 |
| `distanceKm` | 可选，作者标注的当天里程。build 时与路网实测对比，偏差大就告警 |

`rows` 里三样都要有：**时间、动作、交通方式**。只写“古龙山大峡谷”是景点清单，不是行程。

## days[].legs[]

```json
{"from": "wd", "to": "sdl", "nav": "d3_a", "dashed": false, "label": "🛣 S60 合那高速"}
```

| 字段 | 说明 |
|---|---|
| `from` / `to` | spot 的 `id`。必须存在 |
| `nav` | 可选。`navData` 里的键。有它 → 导航视图里沿真实道路画；没有 → 两种视图都是直线 |
| `dashed` | 虚线。航班、高铁、以及“只是示意方向”的段用它 |
| `label` | 说明文字，不渲染，只给读数据的人看 |

规则：
- **只有驾车段配 `nav`**。飞机、高铁、机场到车站的转场，直线虚线反而更诚实。
- 环线要拆成逐段往返（`wd→dn`、`dn→hsh`、`hsh→wd`），不要写一条闭合环——导航视图会连成一圈绕路。
- 一般一天 1–4 段。超过 5 段说明这天太碎，考虑合并。

## spots[]

```json
{"id":"sdl","day":3,"name":"三叠岭瀑布","lat":22.991804,"lng":106.674286,
 "type":"fall","note":"靖西市湖润镇…免费开放，水雾大备雨衣","opt":"首选","days":[3,7]}
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一，`legs` 靠它引用。建议拼音缩写 |
| `day` | 主属天数，决定图钉颜色和 D{n} 角标 |
| `days` | 可选，额外归属的天数（如连住 3 晚的酒店 `[1,2,3]`、两天的机场 `[1,7]`） |
| `name` | 图上显示的名字，**越短越好**，超过 10 字会压住邻居 |
| `lat` / `lng` | GCJ-02。写反了 build 会报坐标越界 |
| `type` | `airport` `rail` `hotel` `scenic` `town` `city` `fall` `cave` `spring` `wet` `peak` `food` …（见模板顶部 `TYPE_ICON`，不认识的落回 📍） |
| `icon` | 可选，直接给 emoji 覆盖 `type` |
| `note` | 点开弹窗的内容：**在哪、几点开、多少钱、坑在哪** |
| `opt` | 可选，名字后的小徽标，如 `首选` / `备选`（三选二那类用它） |
| `dx` / `dy` | 可选，像素级微调图钉位置，专治两个点挤在一起 |

只放**会下车的地方**。隧道口、垭口、服务区不进 spots。

## views

```json
"views": {"all": {"center":[23.40,107.00], "zoom":8.3}, "1": {"center":[26.2,111.4], "zoom":4.8}}
```

`center` 是 `[lat, lng]`，注意纬度在前（和 `navData` 一致，和 `--from` 参数的 `lng,lat` 相反）。
键名是 `"all"`、可选 `"full"`、以及每天的 `"1"`…`"n"`。
缺哪天的视角，点这天时地图不动 —— build 会告警。

## navData

```json
"navData": {"d3_a": [[22.416085,107.363031], [22.424187,107.357394], ...]}
```

`[[lat, lng], ...]`，GCJ-02，按行进顺序。由 `scripts/route_tool.py` 生成，不要手写。
命名建议 `d{天}_{起点id}_{终点id}`，例 `d3_wd_sdl`；同一天多段用 `a/b/c` 后缀也可。

## 最小可用骨架

两天、四个点、一段驾车 —— 复制这个改就行：

```json
{
  "meta": {
    "title": "示例 2日游",
    "dateRange": "2026-05-01 ~ 05-02",
    "chips": [{"text": "自驾", "cls": "gray"}],
    "traffic": ["D1：A → B 约 60km / 50min"],
    "tips": ["B 景区 17:00 停止入场"],
    "footnote": "底图为腾讯地图；标点为 POI 实测坐标（GCJ-02）。"
  },
  "days": [
    {"n": 1, "color": "#3B82F6", "name": "出发", "date": "05-01 周五", "theme": "A → B",
     "rows": [["09:00", "A 出发，走 G56", "🚗"], ["10:00", "B 景区游览", "📍"]],
     "foot": "B 停车场在西门，别走东门", "distanceKm": 60,
     "legs": [{"from": "a", "to": "b", "nav": "d1_a_b", "label": "G56"}]},
    {"n": 2, "color": "#14B8A6", "name": "返程", "date": "05-02 周六", "theme": "B → A",
     "rows": [["10:00", "原路返回 A", "🚗"]],
     "legs": [{"from": "b", "to": "a", "nav": "d2_b_a", "label": "G56"}]}
  ],
  "spots": [
    {"id": "a", "day": 1, "days": [1, 2], "name": "A 市", "lat": 30.1234, "lng": 120.1234, "type": "city", "note": "出发点"},
    {"id": "b", "day": 1, "name": "B 景区", "lat": 30.2234, "lng": 120.2234, "type": "scenic", "note": "08:00–17:00"}
  ],
  "views": {"all": {"center": [30.17, 120.17], "zoom": 11}, "1": {"center": [30.17, 120.17], "zoom": 11}, "2": {"center": [30.17, 120.17], "zoom": 11}},
  "navData": {}
}
```

`navData` 空着也能出图，只是导航视图退化成直线。等 `route_tool.py` 取到路再补进去。

## 完整参照

`assets/trip-data.example.json` 是上面那张广西 7 日图的完整数据（7 天 / 17 个点 / 15 段路网）。
它 57KB，**不要整份读进上下文**。要查结构用：

```bash
python -c "import json;t=json.load(open('assets/trip-data.example.json',encoding='utf-8'));print(list(t));print(json.dumps(t['days'][2],ensure_ascii=False,indent=1))"
```
